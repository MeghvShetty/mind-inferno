## DevOps
> Emphasises the collaboration and communication of both software developers and IT operations teams. Automate the process of software delivery and infrastructure changes. 

## Problem that IaC can solve 
- Inability to scale rapidly (_Requires rapid scaling of IT infrastructure._)
- Operation bottlenecks (_Challenge of managing consistenly in scale._)
- Disconnected feedback loops(_Communication gap between software and IT teams._)
- High manual errors(_Increased scale leads to increased human errors._)

## Benefits of Lac
- Declarative (_Specify the desired state of infrastructure, not update._)
- Code Management (_commit, version, trace, and collaborate, just like source code._)
- Auditable (_Compare infrastructure between desired state and current state._)
- Potable (_Build reusable modules across an organisation._)

## Lac Configuration workflow 
- __Scope__ - confirm the resource required for a project. 
- __Author__ - Author the configuration files based on the scope.
- __Initialise__ - Download the provider plugins and initialise directory. 
- __Plan__ - View execution plan for resources created, modified, or destroyed. 
- __Apply__ - Create actual infrastructure resources.
